# Социальная сеть (Social Media Project)

Веб-приложение социальной сети, построенное на **FastAPI** с использованием **SQLAlchemy** для работы с базой данных и **Jinja2** для рендеринга HTML-шаблонов.

## 🚀 Возможности

- **Просмотр постов** — главная страница отображает все посты с пагинацией
- **Просмотр отдельного поста** — полная информация о посте с комментариями
- **Создание постов** — форма добавления нового поста (заголовок, содержание, автор)
- **Комментарии** — возможность оставлять комментарии к постам
- **Поиск** — поиск постов по заголовку и содержанию
- **Профиль пользователя** — страница со всеми постами конкретного автора
- **Случайные цитаты** — интеграция с внешним API (quotable.io) для отображения цитат
- **Счётчики** — ведётся учёт просмотров и лайков каждого поста
- **REST API** — программный доступ к постам в формате JSON

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| **FastAPI** | Веб-фреймворк для создания API и веб-приложений |
| **SQLAlchemy** | ORM для работы с базой данных |
| **SQLite** | Встраиваемая база данных |
| **Jinja2** | Шаблонизатор для генерации HTML |
| **httpx** | Асинхронный HTTP-клиент для внешних запросов |

## 📋 Описание файлов

### Основные файлы приложения

- **main.py** — содержит все маршруты (endpoints) приложения:
  - `GET /` — главная страница
  - `GET /posts/{id}` — просмотр поста
  - `GET /search` — поиск постов
  - `GET /users/{username}` — посты пользователя
  - `POST /posts/create` — создание поста
  - `POST /posts/{id}/comment` — добавление комментария
  - `GET /random_quote` — случайная цитата
  - `GET /api/posts` — API: список постов
  - `GET /api/posts/{id}` — API: один пост

- **database.py** — настройка подключения к SQLite базе данных через SQLAlchemy

- **models.py** — определение моделей данных:
  - `Post` — таблица постов (id, title, content, author, views, likes)
  - `Comment` — таблица комментариев (id, post_id, author, content)

- **crud.py** — функции для работы с данными:
  - `get_posts()` — получить все посты
  - `get_post(id)` — получить один пост
  - `create_post()` — создать пост
  - `search_posts(query)` — поиск постов
  - `get_posts_by_user(author)` — посты автора
  - `add_comment()` — добавить комментарий
  - `get_comments_by_post(post_id)` — комментарии поста

- **init_db.py** — скрипт первоначальной инициализации БД, создаёт 4 тестовых поста

### Шаблоны (Templates)

HTML-шаблоны используют синтаксис **Jinja2** для динамической генерации страниц.

### Стили (Static)

- **style.css** — единый файл стилей для всего приложения с адаптивным дизайном

## 🚦 Инструкция по запуску

### Предварительные требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 2: Инициализация базы данных

```bash
python init_db.py
```

Это создаст файл `social_network.db` и заполнит его тестовыми данными (4 поста).

### Шаг 3: Запуск сервера

```bash
python main.py
```

### Шаг 4: Открытие приложения

Перейдите в браузере по адресу: **http://127.0.0.1:8000**

## 🌐 Маршруты (Endpoints)

### Веб-страницы

| URL | Метод | Описание |
|-----|-------|----------|
| `/` | GET | Главная страница со списком постов |
| `/posts/{id}` | GET | Просмотр поста |
| `/search` | GET | Поиск постов |
| `/users/{username}` | GET | Посты пользователя |
| `/posts/create` | GET/POST | Форма/создание поста |
| `/posts/{id}/comment` | POST | Добавление комментария |
| `/random_quote` | GET | Случайная цитата |

### REST API

| URL | Метод | Описание |
|-----|-------|----------|
| `/api/posts` | GET | Список всех постов (JSON) |
| `/api/posts/{id}` | GET | Один пост по ID (JSON) |

## 📝 Примеры использования API

### Получить все посты

```bash
curl http://127.0.0.1:8000/api/posts
```

### Получить один пост

```bash
curl http://127.0.0.1:8000/api/posts/1
```

### Поиск постов

```
http://127.0.0.1:8000/search?s=технологии
```

## 🔧 Разработка

### Структура базы данных

**Таблица posts:**
- `id` — INTEGER PRIMARY KEY
- `title` — TEXT NOT NULL
- `content` — TEXT NOT NULL
- `author` — TEXT NOT NULL
- `views` — INTEGER DEFAULT 0
- `likes` — INTEGER DEFAULT 0

**Таблица comments:**
- `id` — INTEGER PRIMARY KEY
- `post_id` — INTEGER (связь с posts)
- `author` — TEXT NOT NULL
- `content` — TEXT NOT NULL
